## Operational Issues

### 1. EC2 Instance Freezing (March 3, 9, 11)

Instance became unreachable (SSH timeout, ping 100% loss) three times. AWS showed "running" but the OS was frozen. Required `aws ec2 stop-instances --force` + `start-instances` each time.

**Root cause**: 8GB EBS disk filling to 100% from accumulated Docker images. Each deploy pulls a ~350MB image; old images were never cleaned up. After ~15 deploys, disk full.

**Fix**: Added `docker image prune -f` to deploy pipeline (`.github/workflows/deploy.yml`). Also cleaned 678MB of journal logs (`journalctl --vacuum-size=100M`).

### 2. DST Transition Missed Trade (March 9)

Scheduler missed the 09:35 trade on the first EDT day. APScheduler logged: `Run time of job "Daily Put Selling" was missed by 1:00:00`.

**Root cause**: APScheduler's default `misfire_grace_time` is 1 second. When clocks sprang forward (EST->EDT), the pre-calculated UTC fire time was off by 1 hour, exceeding the grace time.

**Fix**: Set `misfire_grace_time=3700` (just over 1 hour) on both scheduled jobs in `scheduler.py`. Confirmed working on March 13 — trade fired at 09:35 EDT.

### 3. IBKR Mobile App Disrupting Gateway (March 3)

Logging into IBKR mobile app kicked the gateway session (IBKR only allows one session per username). Gateway entered broken state with 0% delta availability.

**Recommendation**: Create a second IBKR username for mobile access. Settings > Users & Access in Account Management.

### 4. Deploy Not Triggering (March 10)

GitHub Actions deploy ran but failed silently on EC2 because disk was full — `docker pull` failed with "no space left on device". Container kept running old image.

## Backtest Prototype (ThetaData Free Tier)

Built a complete backtester using ThetaData free tier EOD data.

### Files Created
- `backtest/greeks.py` — Black-Scholes pricing, delta computation, IV solving (Brent's method)
- `backtest/thetadata_client.py` — ThetaData v3 REST API client with disk caching, rate limiting (3.5s/req)
- `backtest/backtester.py` — Strategy simulation (0.15 delta, 90 DTE, 60% TP, 3x SL)
- `backtest/run_backtest.py` — Entry point
- `backtest/data/` — Cached CSV files (SPY prices, 13 monthly option chains, results)

### Results (March 2025 - February 2026, 1 year, EOD)
- 233 trades, 89.7% win rate
- PCR: 27.0% (matches David Sun's 25-27% prediction)
- Avg DIT: 28.3 days
- Total P/L: $38,140
- Max drawdown: -$34,623
- 16 stop losses all clustered in April 2025 tariff crash
- SL exits averaged 5.1x instead of target 3x (EOD-only checking limitation)

### Key Backtest vs Live Differences
- Entry at EOD close vs 9:35 AM open (different trade profile entirely)
- Monthly expirations only vs any weekly
- SL checked at EOD vs intraday (biggest impact — pessimistic bias)
- No commissions, no slippage, no IV smile effects
- Avg book size: 18.4 (backtest) vs ~25-38 (live)

### Data Source Comparison
- ThetaData free: EOD options, no greeks, ~1 year history
- ThetaData Value ($40/mo): intraday, greeks from 2020+ (CTA tape limitation on SPY underlying)
- OptionsDX ($178 one-time): 5-min data, 2010+, pre-computed greeks — best value for production backtest
- LambdaClass: free, EOD, 2008-2025, but no intraday
- IBKR: cannot provide expired options data at all
